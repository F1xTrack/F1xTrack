# Основные проекты

Из интересного и более-менее актуального могу отметить:

* [BeatBench](https://github.com/F1xTrack/BeatBench) - Бенчмарк для ИИ, оценивающих их умение создавать карт в BeatSaber по нативному вводу аудио(на моделях типа Gemini/Meta Muse) или по спектрограммам(все, поддерживающие мультимодальный ввод). На удивление, Gemini топ-1 в нём(пусть и 4 Argon) по моим тестам. Результаты бенчмарка опубликую как-нибудь позже, как появятся деньги на тотальное тестирование большого числа моделей
* [BeatForge](https://github.com/F1xTrack/BeatForge) - Штука, чтобы генерить нейронками карты в Beat Saber. Тут мы специально нейронке даём максимум, в отличие от [BeatBench](https://github.com/F1xTrack/BeatBench), чтобы она сделала реально конфетку. _Дожили, вайбкодим карты для битсейбера_
* [ASEVOT(Aperture Science Experimental Virtual Object Transport)](https://asevot.com) - эту штуку, ещё очень давно я изначально создавал, чтобы файлики различные и видосики с Ютуба кидать кенту, у которого строжайший родительский контроль, а в Вацап кидать видео долго и тяжело, ещё и качество в итоге низкое будет. Но теперь оно разрослось во что-то прям большое, я иногда прям поражаюсь. Тупо, по-факту Гугл диск, смог разростись в какой-то огромный портал из всяких разных штук типа сократителя ссылок, скачивалки с Ютуба, автосжималки видео в кучу разных разрешений, поисковой системой, чатом с нейронкой и тд. Там ещё и мой школьный проект на Инженеры Будущего [есть](https://school.asevot.com)
* [GW6 Voice Assist](https://github.com/F1xTrack/gw6-stt-sqrt) -
 С помощью этой штуки можно спрашивать нейронку с часов(в моём случае - Galaxy Watch 6) по вводу с микрофона и получать ответ, в т.ч с поддержкой LaTeX и SVG схемок. Ну, и тут понятно зачем, есть режим изменения яркости при показе ответа. Как говорится, _Думайте. Подписаться_
* [BetterDemo](https://github.com/F1xTrack/BetterDemo) - Это штука для крутых демок в дискорде: можно показывать свою вебку, можно блюрить/скрывать экран, ваще хайп, как будто стримишь своим друзьям, круть в общем. А ещё этой имбой можно управлять с телефона без стримдека. Дальше, как следует из названия, я планировал это интегрировать с BetterDiscord, но как-нибудь потом
* [7TV in Extera](https://github.com/F1xTrack/7TV-Extera) - Это плагин для Экстераграмма/Аюграмма, чтобы как в приложении Frosty, 7TVшные и Твичовские смайлики вставлялись в сообщения. Но только для крутых с тг премом, учитывайте. Все анимашки, отображение другим юзерам, всё имеется
